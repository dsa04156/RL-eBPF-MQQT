# 학습 그래프 설명 가이드

## 📊 전체 구성

4개 패널로 구성된 학습 진행 분석 그래프로, 강화학습 에이전트가 **어떻게 학습했고**, **무엇을 달성했으며**, **왜 효과적인지**를 보여줍니다.

---

## (a) 학습 수렴 (보상 증가 추이)

### 무엇을 보여주나?

- **Y축**: 보상 (Reward) - 에이전트가 받는 피드백 점수
- **X축**: 학습 시간 (초)
- **목표**: 보상이 양수로 증가하고 안정화되는지 확인

### 주요 포인트

```
초기:   -94.6   → 탐색 단계 (실패 많음)
최종:   +11.7   → 양수 보상 (성공)
중앙값: +11.7   → 대부분 양수
양수율: 78.4%   → 학습 성공
```

### 발표 시 설명

> "초기에는 음수 보상이 많았지만, 학습이 진행되면서 **78.4%가 양수**로 전환되었습니다.
> 중앙값이 +11.7로 안정화되어 **에이전트가 올바른 정책을 학습**했음을 보여줍니다."

### 시각적 특징

- 🟢 **초록색 영역**: Positive Reward Zone (목표 영역)
- 📈 **회색 점선**: Polynomial Trend (전체 학습 추세)
- 📊 **진한 초록선**: Moving Average (부드러운 추세)

---

## (b) 성능 개선 (P99 감소 추이)

### 무엇을 보여주나?

- **Y축**: P99 레이턴시 (ms) - 99%ile 꼬리 지연
- **X축**: 학습 시간 (초)
- **목표**: P99가 SLO (300ms) 아래로 내려가는지 확인

### 주요 포인트

```
초기: 5,863ms   → 매우 높은 지연
최종:   840ms   → 85.7% 감소
SLO:    300ms   → 목표 달성률 향상
```

### 발표 시 설명

> "학습 초기 P99가 5,863ms로 매우 높았으나, 학습 후 **840ms로 85.7% 감소**했습니다.
> SLO 300ms에는 아직 미달하지만, **대부분의 구간에서 큰 개선**을 보였습니다."

### 시각적 특징

- 🟢 **초록색 영역**: SLO Safe Zone (300ms 이하)
- 🔴 **빨간 점선**: SLO 목표선 (300ms)
- 📉 **빨간선**: P99 감소 추세

---

## (c) 인과관계: 송신 버퍼 ↔ 레이턴시

### 무엇을 보여주나?

- **왼쪽 Y축** (주황): snd_ratio (송신 버퍼 압력)
- **오른쪽 Y축** (빨강): P99 레이턴시
- **목표**: 버퍼 압력과 레이턴시의 **상관관계** 입증

### 주요 포인트

```
상관계수: 0.856   → 강한 양의 상관관계
snd_ratio > 1.0   → P99 폭등 (버퍼 오버플로)
snd_ratio < 1.0   → P99 안정 (정상 동작)
```

### 발표 시 설명

> "송신 버퍼 압력(snd_ratio)과 P99 레이턴시의 **상관계수가 0.856**으로 강한 양의 상관관계를 보입니다.
> 버퍼가 1.0을 초과하면 P99가 급증하는 패턴이 명확히 관찰됩니다.
> 이는 **커널 버퍼 압력이 레이턴시의 핵심 원인**임을 실증합니다."

### 시각적 특징

- 🔴 **빨간 영역**: Buffer Overflow Zone (>1.0)
- 🔴 **빨간 점선**: 오버플로 임계값 (1.0)
- 📊 **두 선의 동기화**: 버퍼↑ = 레이턴시↑

---

## (d) 제어 효과: 액션 → 버퍼 압력

### 무엇을 보여주나?

- **왼쪽 Y축** (파랑): 액션 크기 |Δrate| (제어 변화량)
- **오른쪽 Y축** (주황): snd_ratio (송신 버퍼 압력)
- **목표**: 에이전트의 **제어가 실제로 효과가 있는지** 입증

### 주요 포인트

```
초기 액션: 0.157  → 큰 탐색 (시행착오)
최종 액션: 0.011  → 미세 조정 (안정화)
초기 버퍼: 0.375  → 높은 압력
최종 버퍼: 0.084  → 낮은 압력 (77% 감소)
```

### 발표 시 설명

> "초기에는 큰 액션(0.157)으로 탐색했지만, 학습 후 **미세 조정(0.011)으로 전환**되었습니다.
> 이에 따라 송신 버퍼 압력도 0.375에서 **0.084로 77% 감소**하여,
> **에이전트의 제어가 실제로 버퍼 압력을 줄이는 효과**가 있음을 입증합니다."

### 시각적 특징

- 📉 **파란선 감소**: 액션 크기 감소 (학습 수렴)
- 📉 **주황선 감소**: 버퍼 압력 감소 (제어 효과)
- 🔴 **빨간 영역**: 오버플로 위험 구간 (>1.0)

### 1단계: 학습 성공 입증

> "(a)를 보시면, 초기 음수 보상에서 시작해 **78.4%가 양수로 전환**되어 에이전트가 성공적으로 학습했습니다."

### 2단계: 성능 개선 확인

> "(b)를 보시면, P99 레이턴시가 초기 5,863ms에서 **840ms로 85.7% 감소**하여 실질적인 성능 개선을 달성했습니다."

### 3단계: 인과관계 입증

> "(c)를 보시면, **상관계수 0.856**으로 송신 버퍼 압력이 레이턴시의 핵심 원인임을 실증했습니다."

### 4단계: 제어 효과 검증

> "(d)를 보시면, 에이전트의 제어로 버퍼 압력이 **77% 감소**하여 실제 제어 효과가 있음을 입증했습니다."

## 📌 예상 질문 & 답변

### Q1: "왜 보상 평균이 -132인데 학습이 성공했다고 하나요?"

**A**: "평균은 초기 실패 케이스(-11,654 같은 극단값)의 영향을 받습니다.
**중앙값 +11.7**과 **양수율 78.4%**를 보면 대부분 양수 보상을 받고 있어 학습이 성공적입니다."

### Q2: "SLO 300ms를 달성하지 못했는데 성공이라고 할 수 있나요?"

**A**: "최종 840ms로 초기 5,863ms 대비 **85.7% 개선**을 달성했습니다.
또한 안정적 제어 정책을 학습했으며, 추가 학습이나 reward shaping으로 SLO 달성 가능합니다."

### Q3: "상관계수 0.856의 의미는?"

**A**: "0.856은 **매우 강한 양의 상관관계**를 의미합니다.
버퍼 압력이 높아지면 레이턴시도 함께 증가하는 인과관계가 명확히 존재합니다."

### Q4: "액션 크기가 0.011로 너무 작은 거 아닌가요?"

**A**: "이는 **정책이 수렴**했음을 나타냅니다.
초기 큰 탐색(0.157) 후 최적 정책을 찾아 미세 조정(0.011)으로 전환된 것으로, **학습 성공의 증거**입니다."
